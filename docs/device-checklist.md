# 真机验证清单

Windows 与 Android 的原生行为只能在实际设备上确认。开发机（Linux，没有 Android SDK，也没有 Windows）上无法完成，以下项目**都还没有在实际设备上验证**。逻辑部分已有 Widget 测试、golden 测试与 Linux 浏览器测试覆盖；本清单只列必须在设备上看的部分。

每项通过后在方括号里打勾，并在“记录”里写设备型号、系统版本、日期与结论（不通过时写现象）。

## 准备

- Windows：Visual Studio C++ 工具链，开启开发者模式（pdfrx 需要），运行 `scripts/build-windows.ps1`。
- Android：SDK、NDK、`cargo-ndk` 与三个 Rust Android target，运行 `scripts/build-android.sh`。要测通知，先把 Firebase 项目的 `google-services.json` 放到 `client/android/app/`，服务端配置 `[push] enabled = true` 与 `fcm_credentials`（Firebase 服务账号密钥）。
- 服务端：设备可达的任意实例。Work 相关项目需要执行节点。

## Windows

- [ ] 启动：Rust DLL 加载，登录、流式回复、审批与重连正常。
- [ ] 输入法：微软拼音、搜狗、注音分别验证组字、候选框位置、换行、在输入框之间切换，以及 Ctrl+Enter；组字期间不得误发送。
- [ ] 睡眠与唤醒：输出进行中让电脑睡眠，唤醒后几秒内重连并补齐（runner 收到 `WM_POWERBROADCAST` 后立即重连，不等旧连接超时）。
- [ ] 网络变化：断开并恢复网络后自动恢复，命令不重复执行。
- [ ] 会话保持：登录后关闭并重新打开应用，无需重新登录；在凭据管理器里能看到 RyzHub 保存的条目；退出登录后条目被删除，重开应用回到登录页。
- [ ] 外部账号登录：系统浏览器打开提供方，完成后回到应用并登录。
- [ ] MCP Apps：插件页面在 WebView2 中显示，使用独立的数据目录；页面里的工具调用与高度调整正常。
- [ ] 字体与选择：中英混排、代码里的中文、超出字体子集的字符（记录缺字与回退）；长列表中拖选、双击选词，流式更新期间选择保持稳定。
- [ ] 帧率：长对话滚动与流式 Markdown、代码块输出时记录帧率（DevTools 性能视图）。
